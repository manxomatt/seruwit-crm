Peta Integrasi Antar Modul

Aliran data dan event yang menghubungkan 5 modul dalam klaster

Desain: Predictive Maintenance Alert

Command baru yang scan jadwal servis dan kirim notifikasi proaktif — gap paling kritis di Maintenance

Alur command: MaintenanceScanDue
1
Query semua maintenance_schedules yang is_active = true
2
Untuk interval_type=mileage: cek vehicle.odometer_km + threshold_km ≥ next_service_odometer
3
Untuk interval_type=calendar: cek next_service_date ≤ today + threshold_days
4
Buat GenericNotification ke user dengan permission maintenance,view
5
(Opsional) Auto-buat draft WorkOrder dari jadwal yang sudah lewat
Konfigurasi threshold (per tenant di .env / config)
Config keyDefaultKeterangan
maintenance.alert_km_before500Alert saat 500 km sebelum jadwal mileage
maintenance.alert_days_before14Alert saat 14 hari sebelum jadwal kalender
maintenance.auto_create_wofalseOtomatis buat draft WO saat jadwal terlampaui
Schedule di routes/console.php: ->daily() — cukup sekali sehari di awal hari kerja.

Desain Halaman: Driver Scoring (5 pages)

Spesifikasi content dan data per halaman React/Inertia yang perlu dibuat

1. Leaderboard/Index GET /scoring/leaderboard
Filter periode: minggu ini / bulan ini / custom range
Kartu rank per driver: nama, foto, skor rata-rata, breakdown event
Data: DriverScoreAggregator::leaderboard($from, $to)
2. Driver Detail GET /scoring/drivers/{driver}
Grafik trend skor 30 hari (sparkline harian)
Kalender heat-map: tiap hari warna sesuai skor (hijau–merah)
Daftar event terbaru + riwayat award insentif
3. Driving Events GET /scoring/events
Feed semua event dengan filter: jenis, severity, vehicle, driver, tanggal
Badge severity (warning/critical) dengan poin_delta yang dikurang
Link koordinat GPS ke peta Leaflet (reuse komponen dari Tracking)
4. Incentive Rules GET /scoring/incentives
CRUD aturan insentif: form inline (periode, min_score, min_days, reward)
Tombol "Evaluasi Sekarang" → POST /incentives/evaluate → tampilkan driver yang lolos
Daftar award pending — update status: approved / paid
5. Settings GET /scoring/settings/edit
Form edit semua threshold di driver_scoring_settings — satu baris per field dengan label deskriptif dan satuan (kph, detik, poin)
Preview dampak: "Dengan setting ini, jika driver dari 80 → 60 kph dalam 2 detik = harsh brake"
Tombol "Reset ke default" untuk kembalikan ke nilai awal sistem
Perubahan setting tidak retroaktif — hanya berlaku untuk event baru ke depan

Roadmap Implementasi

Urutan berdasarkan value / effort ratio — paling atas = paling besar dampaknya dengan effort terkecil

Driver Scoring Frontend
TINGGI ~3 hari DriverScoring
  • Buat 5 halaman React: Leaderboard, Driver Detail, Driving Events, Incentive Rules, Settings
  • Backend 100% siap — controller, routes, support classes semua sudah ada
  • Leaderboard: filter periode, kartu rank, breakdown event per driver
  • Driver Detail: grafik trend 30 hari + calendar heatmap + award history
  • Incentive Rules: CRUD + tombol evaluasi + daftar award pending/paid
Maintenance Predictive Alert
TINGGI ~1 hari Maintenance
  • Artisan command maintenance:scan-due — query schedules mendekati due
  • Bandingkan vehicle.odometer_km vs next_service_odometer dengan buffer 500 km
  • Bandingkan next_service_date vs today + 14 days
  • Kirim notifikasi ke semua user maintenance,view dengan detail kendaraan & jadwal
  • Schedule daily di routes/console.php
Fleet Fuel Analytics
SEDANG ~2 hari Fleet
  • Halaman Analytics per kendaraan: grafik km/L per 10 fill terakhir (data sudah ada di fuel_logs.km_per_liter)
  • Total biaya BBM per bulan (liters × price_per_liter) dengan trend naik/turun
  • Tabel anomaly: highlight baris yang anomaly_flags tidak null dengan kode dan pesan
  • Perbandingan efisiensi antar kendaraan sejenis (fleet-wide ranking)
GPS Historical Playback
SEDANG ~2 hari Tracking
  • Tambah page "Riwayat Rute" per kendaraan dengan date picker
  • Query vehicle_positions per vehicle_id + date range, urutkan by recorded_at
  • Render sebagai L.polyline di Leaflet dengan animasi (marker bergerak sepanjang polyline)
  • Tampilkan driving events dari DriverScoring pada posisi yang sesuai (pin dengan warna severity)
Document Compliance Dashboard
SEDANG ~1 hari Document
  • Widget ringkasan: expiring dalam 30 hari, 60 hari, sudah expired — per tipe dokumen
  • Tabel dokumen kritis dengan link langsung ke kendaraan/pengemudi
  • Integrasi di Vehicle Show: panel "Dokumen" dengan status expiry terdekat
Geofencing (Future)
RENDAH ~4 hari Tracking
  • Tabel baru: geofences (name, polygon GeoJSON, alert_on: enter/exit/both)
  • PositionIngestor: setelah simpan posisi, cek apakah masuk/keluar geofence (point-in-polygon)
  • Trigger notifikasi ke fleet admins saat event enter/exit terdeteksi
  • UI: editor polygon di Leaflet (draw plugin) untuk define zona
